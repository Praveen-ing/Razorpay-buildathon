1. **Browser Setup**:
   - Open Chrome or Edge and navigate to `http://localhost:8501`.
   - Set zoom to **90% or 100%** so all 6 KPI metric cards and tabs are cleanly visible without horizontal scrolling.
   - Ensure the light theme is active (pure white canvas with crisp borders).
2. **Terminal Setup (Optional for wrap-up)**:
   - Have a PowerShell terminal open in the repo root with the command `uv run pytest` ready to show the 52 passing tests.
3. **Audio Check**:
   - Speak with an enthusiastic, clear, confident pace.
   - Keep a bottle of water nearby.
4. **Recording Tip**:
   - If you fumble a word, don't stop the recording! Simply pause for 2 seconds, take a breath, and re-read the sentence. You can edit the pause out, or keep it flowing naturally.
